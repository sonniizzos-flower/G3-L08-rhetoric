# 第八課　修辭總複習（互動動畫教材）

寄居蟹「小寄」帶領的海洋主題教學網頁，供國小資源班使用。內容依第八課教材順序：設問、頂真、類疊、鑲嵌、感嘆，共 38 頁。

純 HTML / CSS / JavaScript，不需要建置、不需要網路套件，也不依賴任何外部服務。

## 檔案結構
```
index.html        首頁（教材主頁）
css/style.css     版面與動畫
js/app.js         教材資料、播放控制、語音、答題邏輯
assets/           寄居蟹 SVG、網站圖示
.nojekyll         讓 GitHub Pages 直接提供檔案
```

## 部署到 GitHub Pages
1. 在 GitHub 建立新儲存庫（例如 `lesson8-rhetoric`），把本資料夾內**所有檔案**（含 `.nojekyll`）上傳到儲存庫根目錄。
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約一兩分鐘後，網址為 `https://<帳號>.github.io/<儲存庫名稱>/`。

本機試用：直接雙擊 `index.html` 即可；若瀏覽器限制，可在此資料夾執行 `python -m http.server`，再開 `http://localhost:8000`。

## 使用說明
- 空白鍵播放／暫停，←／→ 換頁，R 重播本頁，F 全螢幕，M 語音開關，1／2／3 選答案，Esc 離開。
- **自動播放**：依序播放，題目頁留 10 秒思考後公布答案。**互動教學**：學生點選後才顯示答案。
- 語音使用瀏覽器內建的中文語音（建議 Windows 的 Edge，有自然語音）。找不到中文語音時以字幕呈現。
- 錄影：按「錄影模式」，先按 Win+Alt+R 開始錄影，再按空白鍵開始播放。

## 修改教材內容
所有課文句子、選項與解析都在 `js/app.js` 最前面的 `UNITS`（五個單元）與 `PRAC`（綜合練習）。

## 內容出處
修辭名稱、課文例句與「教材解析」文字皆取自第八課教材；「小寄說明」與答案原因為簡化說明。
